## 为远程 Hosts 的"本地保存路径"新增启用开关

在 EditHostsInfo 侧边抽屉中，远程方案的"本地保存路径"区块上方新增了一个 Switch 开关
（`save_path_enabled`），默认开启。关闭后即使配置了 save_path 也不会写入文件，
对 hosts 方案（as_hosts=true）和下载/触发型方案（as_hosts=false）均生效。

修改的文件：
- `src/common/data.d.ts` — 新增 `save_path_enabled?: boolean` 字段
- `src/renderer/components/EditHostsInfo.tsx` — 在 save_path 区块顶部加 Switch 开关行，
  开关关闭时禁用路径输入框和浏览按钮
- `src/renderer/components/EditHostsInfo.module.scss` — 新增 `.save_path_header` 样式类
- `src-tauri/src/refresh.rs` — 读取 `save_path_enabled`，为 false 时跳过 hosts 方案的
  `write_save_copy`，并在下载/触发型方案中将 save_path 视为 None（走触发型逻辑）
- 9 种 i18n 语言文件（zh/zh-hant/en/ja/ko/de/fr/tr/pl）各新增 `save_path_enabled`
  和 `save_path_enabled_desc` 文案

TypeScript 和 Rust cargo check 均编译通过。

## 新增"显示右侧内容"开关 (show_content)

在 EditHostsInfo 编辑表单中，`as_hosts` 开关和 `save_path` 之间新增了一个 Switch 开关
（`show_content`），默认开启。作用于所有类型的 hosts 条目，控制选中该条目后右侧主
编辑器区域是否显示其内容。关闭时编辑器清空不加载内容，条目仍保留在列表中。

修改的文件：
- `src/common/data.d.ts` — 新增 `show_content?: boolean` 字段
- `src/renderer/components/EditHostsInfo.tsx` — 在 as_hosts 和 save_path 之间插入
  show_content Switch 行
- `src/renderer/components/Editor/HostsEditor.tsx` — 读取 `show_content`，为 false 时
  loadContent 直接清空编辑器不加载内容；新增 refShowContent ref + useEffect 同步；
  hostsId/showContent 变化时重新加载
- 9 种 i18n 语言文件各新增 `show_content` 和 `show_content_desc` 文案

TypeScript 编译检查通过（零错误）。

## 问题1修复：下载型方案刷新后编辑器空白

下载型方案（as_hosts=false + save_path）使用 `download_to_file` 流式写入磁盘，
但从未写入 `entries` 缓存。前端 `getHostsContent(id)` 从 entries 读取 → 返回空 →
编辑器空白。修复：在 `refresh.rs` 下载成功后读回文件内容写入 entries 缓存，
二进制文件写入占位信息。
